# Visibility schematic

`visibility_schematic.tikz` is the figure fragment from the submitted paper.
It uses `figures/poloidal.png` and `figures/qi_nfp3_toroidal.png`, copied without
changes from the paper assets. The two background files contain identical image
data; the figure applies different crops and overlays to them.

Include the fragment from this directory in a LaTeX document that loads
`graphicx`, `subfig` and `tikz`, with the `arrows.meta` and `positioning` TikZ
libraries. The fragment contains its caption and two annotated panels.
